# 🚀 Guide de Démarrage Rapide - ESP Budget

## Connexion à la Plateforme

### 1. Accès à l'application
- Ouvrez votre navigateur
- Allez sur `http://localhost:5173`
- Vous verrez la page d'accueil d'ESP Budget

### 2. Première connexion
Cliquez sur **"Se connecter"** et utilisez un des comptes de démonstration :

| Rôle | Email | Mot de passe | Accès |
|------|-------|--------------|-------|
| **Administrateur** | admin@esp.sn | password123 | Gestion complète |
| **Agent** | agent@esp.sn | password123 | Demandes budgétaires |
| **Chef Département** | chef@esp.sn | password123 | Validation départementale |
| **Direction** | direction@esp.sn | password123 | Arbitrage centralisé |
| **Recteur** | recteur@esp.sn | password123 | Approbation finale |

### 3. Changement de mot de passe (OBLIGATOIRE)
⚠️ **Sécurité** : Changez immédiatement votre mot de passe après la première connexion !

1. Connectez-vous avec votre compte
2. Cliquez sur votre nom en haut à droite
3. Sélectionnez "Paramètres"
4. Changez votre mot de passe

## 🎯 Utilisation par Rôle

### 👤 Agent
**Fonctionnalités principales :**
- Créer des demandes budgétaires
- Suivre le statut de vos demandes
- Consulter l'historique

**Comment créer une demande :**
1. Allez dans "Nouvelle Demande"
2. Remplissez tous les champs obligatoires
3. Ajoutez des pièces justificatives si nécessaire
4. Soumettez la demande

### 👨‍💼 Chef de Département
**Fonctionnalités principales :**
- Valider/rejeter les demandes de votre département
- Consolider le budget départemental
- Gérer votre équipe

**Comment valider une demande :**
1. Allez dans "Validation des Demandes"
2. Consultez les demandes en attente
3. Cliquez sur "Valider" ou "Rejeter"
4. Ajoutez un commentaire si nécessaire

### 🏢 Direction
**Fonctionnalités principales :**
- Arbitrage centralisé des budgets
- Vue globale de tous les départements
- Rapports consolidés

**Comment faire l'arbitrage :**
1. Allez dans "Budget Global"
2. Consultez les budgets départementaux
3. Effectuez les ajustements nécessaires
4. Validez le budget consolidé

### 🎓 Recteur
**Fonctionnalités principales :**
- Approbation finale des budgets
- Signature électronique
- Vue d'ensemble institutionnelle

**Comment approuver un budget :**
1. Allez dans "Approbation Rectorale"
2. Examinez le budget consolidé
3. Effectuez les derniers arbitrages
4. Signez électroniquement

### 🔧 Administrateur
**Fonctionnalités principales :**
- Gestion des utilisateurs
- Configuration système
- Maintenance et sauvegarde

**Comment gérer les utilisateurs :**
1. Allez dans "Gestion Utilisateurs"
2. Créez de nouveaux comptes
3. Modifiez les rôles et permissions
4. Gérez les comptes inactifs

## 📊 Tableau de Bord

Chaque utilisateur voit un tableau de bord adapté à son rôle :
- **Statistiques** : Demandes en cours, validées, rejetées
- **Graphiques** : Évolution des budgets, répartition par département
- **Notifications** : Alertes en temps réel
- **Actions rapides** : Liens vers les fonctionnalités principales

## 🔍 Recherche et Filtres

Utilisez les filtres pour trouver rapidement vos informations :
- **Par statut** : Brouillon, Soumise, Validée, Rejetée
- **Par département** : Filtrez par département
- **Par date** : Période spécifique
- **Par montant** : Fourchette de montants

## 📱 Interface Mobile

- **Formulaires** : Adaptation automatique
- **Tableaux** : Défilement horizontal
- **Graphiques** : Redimensionnement automatique
